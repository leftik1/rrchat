# Code Reviewer Skill

When analyzing or writing program code, follow these principles:
1. Assess algorithm correctness, exception handling, and edge cases (nil/null, overflow, resource cleanup).
2. Verify security: injections (SQL/Command/XSS), data leaks, safe handling of file paths and user inputs.
3. Keep architecture simple: follow YAGNI, avoid unnecessary abstractions, favor simplicity.
4. Provide minimal, self-contained, actionable improvements.
