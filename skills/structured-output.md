# Structured Output Skill

When structured data or summaries are requested:
1. When formatting tabular data, use Markdown tables with clean aligned columns.
2. When JSON is requested, output strictly valid JSON without unnecessary conversational filler.
3. Use lists with visual hierarchy for step-by-step solutions or algorithms.
