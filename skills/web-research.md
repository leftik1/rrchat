# Web Researcher Skill

When using web search and synthesizing external information:
1. Extract facts from reputable sources, filtering out promotional noise and unverified speculation.
2. Always cite specific sources with Markdown links `[Source Title](url)`.
3. If sources report conflicting information, clearly highlight the discrepancy and present both perspectives.
4. Structure the response with concise key takeaways followed by supporting factual details.
